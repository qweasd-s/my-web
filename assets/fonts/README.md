# Fonts

All fonts are locally hosted, subsetted to the characters used across `index.html` and `work/*.html`, and licensed under the SIL Open Font License 1.1.

| File | Family | Source | License |
| --- | --- | --- | --- |
| `noto-sans-sc.woff2` | Noto Sans SC (variable 100–900) | [google/fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc) | `licenses/OFL-NotoSansSC.txt` |
| `archivo.woff2` | Archivo (variable 100–900) | [google/fonts](https://github.com/google/fonts/tree/main/ofl/archivo) | `licenses/OFL-Archivo.txt` |
| `ibm-plex-mono-regular.woff2` | IBM Plex Mono | [google/fonts](https://github.com/google/fonts/tree/main/ofl/ibmplexmono) | `licenses/OFL-IBMPlexMono.txt` |

The subsets were generated with the Google Fonts `text=` API for the exact characters used by the four pages. If you change the copy substantially and see fallback glyphs, regenerate the subsets with the same character set.
